## Highlights

Are you a visual learner and a beginner in coding? Code Reaction is designed for you! 

Code Reaction is an interactive programming educational platform that design to help beginners to learn fundamental coding and game developing concept. 

Users can learn coding concepts like variable declaration and if conditions through animation and games to learn things like how different conditions cause something to happen and what the process in between is. 

### Features:
- **Rule-based code-block validator** to check code block logic and provide targeted error messages for the user to identify the mistake they made. 
- **Interactive mini games and visual** built with p5.js and Matter.js 
- **Lessons and Quizzes**
- **Log in, take notes, and store your notes and quiz results** in our database!

Enjoy different games while learning how to make them!
